# LLM Chat

Консольное Java-приложение для ведения диалога с языковой моделью через локальный сервер **Ollama**.

В приложении сохраняется история текущего диалога и передаётся модели при каждом следующем запросе. Для системной инструкции используется отдельный файл `system-prompt.txt`.

## Требования

Для запуска приложения необходимо установить:

* **Java 21** или выше;
* **Maven 3.9+**;
* **Ollama**;
* модель **llama3.2:1b**.

Проверить установленные версии можно командами:

```bash
java -version
mvn -version
ollama --version
```

## Зависимости

Проект использует:

* Java 21;
* Spring Boot 3.5.16;
* Jackson для работы с JSON;
* Java `HttpClient` для HTTP-запросов к Ollama;
* JUnit и Mockito для unit-тестов.

Все Java-зависимости устанавливаются Maven автоматически из файла `pom.xml`.

Для загрузки зависимостей выполните в корневой директории проекта:

```bash
mvn clean install
```

## Установка и запуск Ollama

Установите Ollama для своей операционной системы.

Убедиться в установке можно через команду:

```bash
ollama --version
```

Запустите локальный сервер Ollama:

```bash
ollama serve
```

По умолчанию Ollama запускается по адресу:

```text
http://localhost:11434
```

Окно терминала, в котором выполняется `ollama serve`, должно оставаться открытым во время работы приложения.

## Загрузка модели

Загрузите необходимую для приложения модель:

```bash
ollama pull llama3.2:1b
```

Проверить установленные модели можно командой:

```bash
ollama list
```

В списке должна присутствовать:

```text
llama3.2:1b
```

## Настройка Ollama и модели

Настройки приложения находятся в:

```text
src/main/resources/application.properties
```

Текущая конфигурация:

```properties
LLM_BASE_URL=http://localhost:11434
LLM_MODEL=llama3.2:1b
```

После этого приложение будет использовать указанные значения.

### Файл `.env.example`

В репозитории также находится пример конфигурации:

```env
LLM_BASE_URL=http://localhost:11434
LLM_MODEL=llama3.2:1b
```

Файл `.env.example` предназначен только для демонстрации настроек.

## Запуск приложения

### 1. Запустить Ollama

В отдельном терминале:

```bash
ollama serve
```

### 2. Убедиться, что модель установлена

```bash
ollama list
```

При необходимости:

```bash
ollama pull llama3.2:1b
```

### 3. Запустить приложение

Из корневой директории проекта выполните:

```bash
mvn spring-boot:run
```

После запуска появится консольный интерфейс:

```text
=================================
           LLM Chat :P
=================================
Введите сообщение для ассистента.
Команды:
  /clear — очистить историю
  /exit  — выйти

Вы:
```

Введите сообщение и нажмите Enter:

```text
Вы: Что такое Java?

Ассистент: Java — это объектно-ориентированный язык программирования...
```

После ответа можно продолжить диалог.

## Сборка и запуск JAR

Сначала соберите приложение:

```bash
mvn clean package
```

После успешной сборки JAR-файл будет находиться в директории:

```text
target/
```

Запустить приложение можно командой:

```bash
java -jar target/llm-chat-1.0.0.jar
```

Перед запуском необходимо убедиться, что Ollama работает и модель `llama3.2:1b` установлена.

## Команды

В консольном интерфейсе доступны команды:

```text
/clear
```

Очищает историю текущего диалога.

```text
/exit
```

Завершает работу приложения.

Пустые сообщения не отправляются в модель.

## Обработка ошибок

Приложение обрабатывает основные ошибки взаимодействия с Ollama:

* Ollama не запущена;
* сервер недоступен;
* указанная модель отсутствует;
* Ollama API вернул ошибку.

Например:

```text
Ошибка при обращении к Ollama: Не удалось подключиться к LLM.
```

После ошибки приложение продолжает работать, поэтому можно повторить запрос после устранения проблемы.

## Архитектура

```text
CLI
 │
 ▼
ChatService
 │
 ▼
LlmClient
 │
 ▼
Ollama API
```

### `ChatCli`

Получает сообщения пользователя и выводит ответы модели.

### `ChatService`

Хранит историю текущего диалога, формирует список сообщений и добавляет ответы модели в историю.

### `LlmClient`

Определяет взаимодействие с LLM.

### `OllamaClient`

Выполняет HTTP-запросы к локальному Ollama API и преобразует JSON-ответы в Java-объекты.
